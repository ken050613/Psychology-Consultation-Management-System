PSYCHOLOGY CONSULTATION MANAGEMENT SYSTEM - How to Use
========================================================

This is a Java Swing desktop application that lets students book
consultation appointments with lecturers. There are two roles:

   - Student  -> view lecturers/slots, book appointments, cancel
                appointments, and give feedback.
   - Lecturer -> publish available slots, view booked appointments,
                and read student feedback.

Data is saved into plain text files in the same folder:
users.txt, slots.txt, appointments.txt, feedback.txt.


BEFORE YOU START (one-time setup)
==================================
1. Install JDK 22 (or newer) on your computer.
   Check by running:   java -version
2. The project uses Maven (see pom.xml). Either:
   - Open the whole "JAVAPROJECT" folder in NetBeans / IntelliJ / VS Code
     and press Run, OR
   - Use the command line (see Step 1 below).


STEP 1 - Compile and run the program
====================================
Open a terminal / Command Prompt and go to the project folder:

         cd "D:\assignment\java project\JAVAPROJECT"

Then compile and run:

         mvn compile
         java -cp target/classes com.mycompany.javaproject.ConsultationManagementGUI

(A window titled "Login" will open.)

TIP: You can also just open the project in NetBeans and click the
Run (green) button.


STEP 2 - Register an account
=============================
1. On the Login window, click the "Register" button.
2. Fill in:
         ID        : your student / lecturer ID
         Name      : your full name
         Email     : your email address (you log in with this)
         Password  : your password
         Role      : choose "Student" or "Lecturer" from the dropdown
3. Click "Register".
   - If all fields are filled, you will see "Registration successful!"
   - You are taken back to the Login window.


STEP 3 - Log in
================
1. On the Login window, type your Email and Password.
2. Click "Login".
   - If the details match, you enter your Dashboard:
       * Students  -> "Student Dashboard"
       * Lecturers -> "Lecturer Dashboard"
   - If they do not match, you get "Invalid credentials."


STEP 4 - STUDENT DASHBOARD
===========================
After logging in as a student you will see these buttons:

   View Lecturers   : shows the list of available lecturers and the slots
                      they have published.
   Make Appointment: type the Lecturer ID and the slot details (date/time)
                      to book a consultation.
   View Appointments: shows only YOUR appointments.
   Cancel Appointment: type the appointment details exactly as shown to
                      cancel it.
   Give Feedback    : type your rating/comments for the lecturer.
   Back             : log out and return to the Login window.


STEP 5 - LECTURER DASHBOARD
============================
After logging in as a lecturer you will see these buttons:

   Manage Slots    : type a slot (e.g. date and time) to publish a new
                     available consultation slot for students to book.
   View Appointments: shows all appointments booked with YOU.
   View Feedback    : shows the feedback students have left.
   Back             : log out and return to the Login window.


TROUBLESHOOTING
================
- "java is not recognized"  : JDK is not installed or not on your PATH.
- Window does not open      : run the commands in Step 1 again and make
                             sure you are inside the "JAVAPROJECT" folder.
- "Invalid credentials"      : log in with the EMAIL and PASSWORD you used
                             when registering (not your ID).
- Registration fails        : every field must be filled in.
- Cannot save data          : make sure the .txt files are in the same
                             folder as the program (they should be, by
                             default).


IMPORTANT NOTES
===============
- Your account is saved in users.txt. The data files must stay in the
  project folder.
- Click "Back" on either dashboard to log out safely.
- This is a GUI (window) program, not a command-line menu.
